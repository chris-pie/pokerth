Just use Dockerfile_WindowsBuild and run following command in it

i686-w64-mingw32.static-qmake-qt5 "CONFIG+=client" pokerth.pro && make release

Docker image also uploaded on hub.docker.com/layers/amlybon/pokerth_windows so you can do

docker run --rm -it -v /path/to/local/source/pokerth-neuro:/src/pokerth amlybon/pokerth_windows bash -c "i686-w64-mingw32.static-qmake-qt5 CONFIG+=client pokerth.pro && make release"

remove CONFIG+=client to build server instead
